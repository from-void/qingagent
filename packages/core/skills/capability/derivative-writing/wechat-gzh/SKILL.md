# 公众号衍生稿

## 分层契约

本篇的标题写法、结构节奏、排版规则**全部由本次请求携带**：`writingPrompt` 是用户选定的写作风格模板，`layoutPrompt` 是选定的排版模板，`privatePrompt` 是本篇补充要求。三者按「排版照 `layoutPrompt`、内容写法照 `writingPrompt`、再叠加 `privatePrompt`」执行；本技能不内嵌任何具体模板内容，只补模板管不到的纪律。

## 撰写纪律

- 基于主文档事实改写，不得新增未经素材/主稿支撑的事实；保留主稿核心结论。
- 不得给主稿对象追加其未自述的行业/阶段/规模定性（如"SaaS公司""头部""独角兽"）；拿不准的类别词一律不用，改用主稿原有表述。
- 主稿是长文时按公众号阅读节奏重新分段与起小标题，但不得为了节奏删掉主稿的关键结论或数据。
- 输出一份完整闭合的 QingML 整文，标题、正文、结尾一次写齐，不留待补占位。

## 风格模板的学习与维护

用户给出 `mp.weixin.qq.com` 链接并要求"学风格/按这个排版"，或要查看、新建、修改、删除公众号风格模板时走这一节；它产出的是**模板数据**，与上面的撰写流程各走各的，不要混在同一轮里。

### 从文章学习风格

1. 先用 `fetchArticle` 抓取链接，它已内置微信正文清洗。
2. 分开分析两类特征：排版侧提取高亮颜色、标题字号与层级、段落长度和小节节奏；写作侧提取语气、内容组织、开头、论证和结尾策略。不要把文章事实写进模板。
3. 调 `style_template_list` 列出现有同槽模板。
4. 必须单独调用 `askUserQuestion`，询问"融合进现有模板"还是"新建模板"，并把现有模板作为可选项；等待用户选择，不替用户决定。
5. 用户选择后调用 `style_template_save`：融合时带现有 id 且保留其有效规则；新建时不传 id。排版与写作都要学习时分别保存两个槽。
6. 简短回报保存的模板名称、槽位和是新增还是更新。

### 模板 CRUD

- 查看清单用 `style_template_list`，看完整规则用 `style_template_get`。
- 新建或修改用 `style_template_save`；`slot=layout` 只写排版规则，`slot=writing` 只写内容写法。
- 删除用 `style_template_delete`；内置模板不可删。修改内置模板后会自动转为用户模板语义。
