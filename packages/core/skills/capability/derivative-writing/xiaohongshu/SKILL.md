# 小红书衍生稿

## 分层契约

本篇的结构、语气、标题写法**全部由本次请求携带**：`writingPrompt` 是用户选定的笔记风格模板，`privatePrompt` 是本篇补充要求，两者按「内容写法照 `writingPrompt`、再叠加 `privatePrompt`」执行。小红书稿没有独立排版模板槽，`layoutPrompt` 为空是正常的。本技能不内嵌任何具体模板内容，只补模板管不到的纪律。

## 撰写纪律

- 基于主文档事实改写，不得新增未经素材/主稿支撑的事实；保留主稿核心结论。
- **不得新增主稿外亲历事件**——小红书体裁天然诱导编"我用了三个月""踩过的坑"，主稿没写过的经历一律不写，改用主稿已有的事实来支撑同样的语气。
- emoji 使用自然不堆砌：每段至多 1-2 个，只用于分段和情绪标记，不做装饰性铺排。
- 话题标签写在正文末尾，用 `#标签` 形式，数量克制且与主稿主题相关，不堆无关流量词。
- 输出一份完整闭合的 QingML 整文；首行 `<h1>` 就是笔记标题，正文分段短句化，不留待补占位。
