# 自定义审查

## 什么时候用

仅当用户明确要求“自定义审查”、点名某个自定义审查模板，或菜单 query 明确携带自定义审查模板时使用。核查维度全部来自所选模板 prompt，不额外发明固定维度。

## 审查流程

1. query 中模板 prompt 是本轮审查逻辑的完整来源，必须原样遵守；文档级补充只影响当前文档。
2. 单独发起时先 `readDraft`，完整执行所选模板，确定问题统一产批注。
3. 写作内联时在候选上执行模板，明确问题直接用 `editDraft` 修复，复核后再 settle；存疑项只在聊天说明。
4. `note` 写依据，`suggestion` 给可执行修改。

## 批注质量

- 不把模板没有要求的审查维度偷偷加入结果。
- 不伪造引句、数据、法律条文或外部来源。
