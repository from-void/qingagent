# 来源核查

## 什么时候用

仅当用户明确要求“来源审查”“来源核查”“核对依据”“是否按素材写”或同义的素材对照核查时使用；用户在最初写作请求里明确要求“写完做来源核查”时可走写作内联形态。普通写作、修改、润色、敏感词、去 AI 味及其他审查都不得主动调用本流程。素材是唯一 ground truth，默认不联网。

## 审查流程

1. `readDraft` 读取当前文档全文。
2. 查看当前会话的素材上下文，并逐份调用 `readMaterial` 读取相关素材全文。若当前会话没有素材，立即停止，不调用 `create_annotation_groups`，聊天只提示：`当前会话没有可对照的素材,请先添加素材再做来源审查`。
3. 从文档抽取可由素材核验的事实断言，优先检查数字、百分比、日期、金额、单位、量级、约数和统计口径。
4. 同时做正向溯源与反向覆盖率核查，只能作以下五类判定：
   - **有据**：素材直接支持该断言；不创建批注，不打扰用户。
   - **口径漂移**：素材值或口径与文中不一致；把能证明差异的素材原句逐字填入 `materialQuote`。
   - **无据**：已查完相关素材仍找不到支持；只有素材确实查不到时才能判定，严禁把素材中可查到的内容判为无据。
   - **数字失真**：单位、量级或约数表达错误；把素材原句逐字填入 `materialQuote`。
   - **素材遗漏**：素材中的核心数据、重要经历或关键结论对主题重要，但文章没有采用；把素材原句逐字填入 `materialQuote`，并把批注锚在最相关章节标题的精确文字上。
5. 单独审查只上报口径漂移、无据、数字失真、素材遗漏。同一断言在正文多处出现时合为一组，需要覆盖全部相同出现处时设置 `all:true`。每组填写 `judgment`；短标题可用“履历时间与素材不符”“金额口径漂移”这类变更类型；口径漂移、数字失真与素材遗漏必须填写 `materialQuote`，且引句必须逐字存在于 `readMaterial` 返回文本；无据类填写 `checkedScope` 说明核查范围，不得伪造引句。可给出对齐素材的 `suggestion`。
6. 模板明确采用默认分级口径时，数字失真与无据=`error`、口径漂移=`warn`、素材遗漏=`info`；模板未要求分级时省略 `severity`。
7. 写作内联时，确认的来源问题直接修复并重新读取复核。素材是否采用等需要用户裁量的覆盖率发现只在聊天里克制说明。
8. query 中的“来源审查指令”是用户长期偏好，必须完整遵守；补充要求只约束本次审查。

## 完成口径

- 完成后聊天只回复一句总括和一张简表，列为“断言 / 判定 / 依据”；“有据”断言不进入表格，不长篇复述素材或正文。
- 没有问题时只用一句话说明已按素材核查且未发现来源问题。
- 不得虚构“脱敏”“红字”“***”等素材标记。
