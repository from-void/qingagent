# 青简产品事实清单(写使用指南的唯一依据,不得编造此外的功能)

## 产品定位
青简是一款 AI 中文写作工作台:左边聊天、右边稿纸。你用说话的方式提需求,AI 直接把文章写进右侧正文;后续修改也用对话完成,每次改动都可以在正文里核对。

## 快速开始(新用户三步)
1. 打开「设置 → 模型」。第一次使用会提示:还没有可用的模型,推荐先接 DeepSeek——写作最便宜;需要模型看图再接 Kimi。配置任意一家即可开始写作。
2. 去 DeepSeek 开放平台(platform.deepseek.com)注册并创建一个 API key(以 sk- 开头),复制。
3. 回到青简,在输入框「粘贴 DeepSeek API key(sk-…)」处粘贴,点「测试连接」可查询连通性与余额。配置成功即可开始写作。

## 核心功能
- 对话写作:输入框描述想写的内容,文章生成到右侧正文;首页有「产品需求文档/竞品分析报告/用户调研报告/需求评审纪要/功能规格说明」等模板一键填充。
- 对话改稿:选中正文文字后说「修改选中文字」,或直接说「第二节改成表格」「口吻更亲切」这类指令;每次修改可核对具体改动。
- 素材:点输入框旁「素材」上传文件(PDF、Word、Excel、图片等),写作时 AI 会读取引用;也支持连接本地文件夹。
- 联网调研:AI 可以联网搜索、抓取网页文章(包括微信公众号文章)做素材。
- 图与图表:说「画张流程图/时序图/甘特图」会生成可再编辑的图表;说「配一张插图」会生成矢量插画;桌面端装了 Codex 还能生成照片级位图。
- 表格与计算:支持复杂表格;涉及求和、均值等计算时 AI 用精确计算,不口算。
- 审查:发布前可以让 AI 把关——敏感词、隐私信息、格式一致性等,以批注形式给出,逐条采纳或忽略。
- 衍生稿:主文档一键衍生公众号推文、小红书笔记、多语种译文,原稿不动。
- 发布:写好的文档可以发布到飞书云文档。
- 技能:输入框旁「技能」可查看/管理 AI 的能力包。

## 进阶技巧
- 安全设置:「设置 → 安全」里是操作确认档位,默认「不再询问」(命令直接执行不打断);可改回「每次询问」。
- 快捷键:Enter 发送,Shift+Enter 换行。
- 会话即文档:首页每张卡片是一篇文档及其完整对话历史,随时回来继续改。

## 常见问题
- 提示模型不可用/余额不足:去「设置 → 模型」点「测试连接」查询连通性与余额;DeepSeek 余额需在其官网充值。
- 生成中想停止:点输入框旁「停止」。
- 担心数据:文档和对话保存在本机。
